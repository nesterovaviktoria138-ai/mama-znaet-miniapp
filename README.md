# МАМА ЗНАЕТ — Mini App v1.0

Первая рабочая демо-версия интерфейса.

## Уже есть
- главный экран;
- профиль малыша и расчёт возраста;
- разделы: развитие, сон, питание, стул, кожа, массаж;
- карточки материалов;
- дневник;
- избранное;
- экран Premium;
- Telegram WebApp SDK;
- адаптивный мобильный дизайн.

## Пока не подключено
- сервер и база данных;
- реальная авторизация Telegram;
- загрузка видео/фото;
- реальная оплата Telegram Stars;
- синхронизация между устройствами;
- админ-панель.

## Запуск
Файлы можно открыть локально для просмотра. Для Telegram Mini App их нужно разместить на HTTPS-хостинге, затем подключить URL приложения к боту через BotFather.

ВАЖНО: токен BotFather не помещается в frontend-код. Реальную оплату Stars подключим через сервер.

Перед коммерческим запуском медицинский контент нужно проверить профильным специалистом.
